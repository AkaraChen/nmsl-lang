# nmsl 文档

nmsl 是一门完整的、静态类型的、面向对象的编程语言。编译器用 Go 编写，把 nmsl 源码翻译为 C，再交给你系统上的 C 编译器生成原生可执行文件。

nmsl 的规范就是 `main` 分支上编译器的行为（[SPEC 序言](../SPEC.md#本规范的地位)）。本目录下的文档是写给使用者的指南；条文以 [SPEC.md](../SPEC.md) 为准。

## 文档用语

nmsl 的官方文字使用统一术语（[SPEC 10.5](../SPEC.md#105-文档用语)）：

| 说法 | 含义 |
|---|---|
| 由目标平台定义 | 结果取决于所用的 C 编译器、优化级别、处理器架构和操作系统 |
| 进程终止 | 进程被操作系统信号结束 |
| reserved for future use | 没有对应的语法或功能 |
| 我们相信开发者 | 编译器与运行时不做检查 |
| 我们都是成年人 | 可见性不执行 |
| 你不需要它 | 功能没有提供 |
| 这是为了简单 | 对用户反馈的回应 |
| 规范如实记录，不解释 | 两种行为互不一致 |

nmsl 程序不会出错，只会终止。
