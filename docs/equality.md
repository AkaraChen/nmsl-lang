# 相等性速查表

nmsl 提供三种比较，每一种都有精确、可预测的定义。本页把它们在常见值组合上的结果列成一张表。把它打印出来，贴在显示器旁边。

## 三条规则

**`a == b`**（SPEC 3.11.1）

1. 任一边是 `null`：结果是 `null`。
2. 两边类型相同：直接比较值。数字比数值；字符串、数组、对象、函数比**地址**。
3. 两边类型不同：两边都转成整数（`to_number`），再比较。

**`a.equals(b)`**（SPEC 3.11.2）

1. 任一边是 `null`：结果是 `null`。
2. 两边都是字符串：比较内容。
3. `a` 是对象，且它的类定义了 `equals`：调用它。
4. 其余情况：与 `a == b` 相同。

**`is(a, b)`**（SPEC 3.11.3）

1. 任一边是 `null`：结果是 `null`。
2. 否则逐字节比较两个值的完整内存表示，包括结构体中的填充字节。

## 表中的记号

- `1`、`0`：nmsl 的真与假（SPEC 3.6）。`print` 输出的就是这两个数字。
- `null`：结果是 `null`。在条件中为假；`print` 输出空行。
- **平台**：由目标平台定义。结果取决于你的 C 编译器、优化级别和处理器。
- `—`：该写法对此组合不适用（数字字面量不能直接写 `.equals`，请先放进变量）。

下表中，`s`、`t` 是 `String` 变量，`a` 是数组变量，`u`、`v` 是两个字段完全相同的不同对象，`x` 是任意非 null 值。

## 结果矩阵

### 数字

| 左 | 右 | `==` | `.equals` | `is` | 说明 |
|---|---|---|---|---|---|
| `1` | `1` | `1` | `1` | 平台 | `is` 比较填充字节 |
| `1` | `1.0` | `1` | `1` | `0` | 类型不同，转成整数后相等；标签字节不同 |
| `1` | `1.9` | `1` | `1` | `0` | `1.9` 转整数是 1 |
| `0.0` | `-0.0` | `1` | `1` | `0` | 数值相等，符号位不同 |
| `true` | `1` | `1` | `1` | 平台 | `true` 就是 1 |
| `0.1 + 0.2` | `0.3` | 平台 | 平台 | 平台 | `bignumber` 的精度随平台变化 |

### 数字与字符串

| 左 | 右 | `==` | `.equals` | `is` | 说明 |
|---|---|---|---|---|---|
| `0` | `"abc"` | `1` | `1` | `0` | `"abc"` 转整数是 0 |
| `1` | `"1"` | `1` | `1` | `0` | |
| `12` | `"12abc"` | `1` | `1` | `0` | 读到 `a` 停止 |
| `3` | `"3.9"` | `1` | `1` | `0` | 读到 `.` 停止 |
| `16` | `"0x10"` | `0` | `0` | `0` | `"0x10"` 转整数是 0 |
| `42` | `" 42"` | `1` | `1` | `0` | 前导空白被跳过 |

### 字符串

| 左 | 右 | `==` | `.equals` | `is` | 说明 |
|---|---|---|---|---|---|
| `"a"` | `"a"` | 平台 | `1` | 平台 | 两个字面量是否合并为同一地址，取决于 cc |
| `s` | `s` | `1` | `1` | 平台 | 同一个地址 |
| `"a" + "b"` | `"ab"` | `0` | `1` | `0` | 堆上的字符串不等于字面量 |
| `"a" + "b"` | `"a" + "b"` | `0` | `1` | `0` | 两次拼接，两个地址 |
| `"abc"` | `"abd"` | `0` | `0` | `0` | |
| `"中文"` | `"中文"` | 平台 | `1` | 平台 | 同上 |

需要比较字符串的内容时，请使用 `equals`。

### 空串与 null

| 左 | 右 | `==` | `.equals` | `is` | 说明 |
|---|---|---|---|---|---|
| `""` | `""` | `null` | `null` | `null` | 空串就是 null |
| `x` | `null` | `null` | `null` | `null` | |
| `null` | `x` | `null` | `null` | `null` | |
| `null` | `null` | `null` | `null` | `null` | |
| `"a"` | `null` | `null` | `null` | `null` | |

`!=` 的结果是对 `==` 的结果取反，`null` 照常传染。因此：

| 写法 | x 是 null | x 不是 null |
|---|---|---|
| `x == null` | `null`（假） | `null`（假） |
| `x != null` | `null`（假） | `null`（假） |
| `!(x == null)` | `null`（假） | `null`（假） |
| `nulls.Is(x)` | `1` | `0` |

判断 `null`，请只使用 `nulls.Is`。详见 [null 与 nulls 包最佳实践](nulls.md)。

### 数组

| 左 | 右 | `==` | `.equals` | `is` | 说明 |
|---|---|---|---|---|---|
| `a` | `a` | `1` | `1` | 平台 | 同一个地址 |
| `[1, 2]` | `[1, 2]` | `0` | `0` | `0` | 两个数组，两个地址 |
| `[1, 2]` | `1` | 平台 | 平台 | `0` | 数组的地址转成整数后与 1 比较 |

### 对象

| 左 | 右 | `==` | `.equals` | `is` | 说明 |
|---|---|---|---|---|---|
| `u` | `u` | `1` | `1` | 平台 | |
| `u` | `v`（类未定义 `equals`） | `0` | `0` | `0` | 默认比较引用 |
| `u` | `v`（类定义了 `equals`） | `0` | 由你的 `equals` 决定 | `0` | |

定义 `equals` 时必须同时定义 `hashCode`（SPEC 5.9）。

## 关系运算

`<`、`<=`、`>`、`>=` 与 `==` 使用同一套规则（SPEC 3.10.4）：

```
print(2 < "10")        // 1：两边转整数
print("b" < "a")       // 平台：比较的是两个字面量的地址
print(null < 1)        // （空行）
```

需要按字典序比较字符串时，请使用 `strcmp`：

```
if (strcmp(s, t) < 0)
    print("s 在前")
```

注意 `strcmp` 在两个字符串**相等**时返回 0。`if (strcmp(s, t))` 在两个字符串**不相等**时进入。

## Map 的键

`Map` 用 `==` 比较键（SPEC 8.5.4），上面的矩阵直接适用：

| 操作 | 结果 |
|---|---|
| `m.put(0, v)` 后 `m.get("abc")` | 找到：`0 == "abc"` |
| 用 `"a" + "b"` 作键存入，用 `"ab"` 查 | 找不到 |
| `m.put(null, v)` | 每次追加一项，永远找不到 |

`Map` 不调用 `equals` 与 `hashCode`。

## 没有 `===`

nmsl 只有一种相等运算符。写 `===` 会得到：

```
unknown operator: ===
```

三种比较已经覆盖了你需要的一切。
